# Battery Panic Website

Modern React/Vite landing page for Battery Panic.

## What is included

- Product hero with direct DMG download.
- Feature sections for low-battery alerts, charging reminders, critical mode, sounds, updates, and privacy.
- Install guide section based on the DMG flow.
- First-launch Privacy & Security guide with the existing screenshot explanation.
- Scroll animations using Motion.
- No API keys or backend services required.

## Run locally

```bash
pnpm install --ignore-scripts
pnpm run dev
```

If you do not use pnpm, any normal Node package manager can run the Vite scripts after installing dependencies.

## Build

```bash
pnpm run build
```

The static output is written to `dist/`.
