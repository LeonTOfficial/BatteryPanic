# Battery Panic 0.5.14

Battery Panic 0.5.14 brings a cleaner, more accurate menu bar battery icon and safer automatic background updates.

## What's new

- Distortion-free menu bar and menu header battery icons.
- Accurate empty, partial, full, charging, and critical battery states.
- One clear charging indicator beside the compact status icon.
- Sparkle updated to 2.9.4.
- Signed updates can download and install automatically when macOS permits it.
- Daily update scheduling, a safe launch check, and manual update checks remain available.
- No analytics or Sparkle system profiling.
- New geometry and rendered-pixel regression tests for the battery icon.

## Download

Attach these files to this GitHub release:

- `outputs/Battery.Panic.0.5.14.dmg`
- `outputs/Battery.Panic.0.5.14.zip`

Recommended for normal users:

1. Download `Battery.Panic.0.5.14.dmg`.
2. Drag Battery Panic into Applications.
3. If macOS blocks the first launch, open System Settings -> Privacy & Security and click Open Anyway.

## Notes

Battery Panic is open source and locally/ad-hoc signed. It is not Apple-notarized yet, so macOS may show the normal first-launch security warning for non-notarized apps.
