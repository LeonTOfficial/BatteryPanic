# Settings

Battery Panic settings are available from the menu bar item.

## Low Battery Alarm

Choose the percentage where the red low-battery warning should appear. The default is 10%.

## Charging Reminder

Battery Panic can show a short blue-green reminder while charging. The default reminder threshold is 80%.

## Overlay

You can adjust pulse speed and pulse intensity.

## Sound

Choose the Battery Panic siren or a macOS system sound. Sounds can be tested in Settings.

## Start At Login

Enable Start at login if Battery Panic should be ready automatically after restarting your Mac.
