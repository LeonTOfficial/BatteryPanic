# Installation

Battery Panic installs like a normal macOS app.

## Download

Use the official download page:

https://leontofficial.github.io/BatteryPanic/download/

Download the latest `.dmg` file, not the green GitHub source-code ZIP button.

## Install

1. Open the downloaded DMG.
2. Drag `Battery Panic` into `Applications`.
3. Open Battery Panic from the Applications folder.
4. Keep the app in the menu bar so it can watch the battery in the background.

## First Launch On macOS

Battery Panic is open source and distributed outside the Mac App Store. Because the app is not Apple-notarized yet, macOS may block the first launch.

If that happens:

1. Open `System Settings`.
2. Go to `Privacy & Security`.
3. Scroll to the bottom.
4. Find the Battery Panic message.
5. Click `Open Anyway`.
6. Confirm the next macOS prompt.

You only need to approve the app once.

## Recommended Setup

- Enable `Start at login` so Battery Panic is ready after restarting your Mac.
- Open Settings once and choose your preferred low-battery threshold.
- Use `Preview Red Screen` to test the overlay safely.
