# Installation

1. Download the latest DMG from the Battery Panic website.
2. Open the DMG.
3. Drag Battery Panic into Applications.
4. Open Battery Panic from Applications.

If macOS blocks the first launch, open System Settings, go to Privacy & Security, scroll down, and click Open Anyway for Battery Panic.

Download page: https://leontofficial.github.io/BatteryPanic/download/
