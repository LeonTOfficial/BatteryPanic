# Privacy

Battery Panic is local-first.

The battery warning itself works on your Mac and does not need an account, cloud service, analytics system, or API key.

## What Stays Local

- Battery percentage.
- Charging state.
- Up to seven days of timestamps, battery percentages, and power-source transitions in local Application Support.
- Low-battery threshold.
- Charging reminder threshold.
- Overlay and sound settings.
- Start-at-login preference.

## Network Access

Battery Panic does not need network access for battery warnings.

The only optional network activity is checking for updates through the public GitHub appcast.

## What Battery Panic Does Not Do

- No analytics.
- No telemetry.
- No tracking.
- No accounts.
- No API keys.
- No battery data upload.
