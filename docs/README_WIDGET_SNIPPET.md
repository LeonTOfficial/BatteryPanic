## Widgets

Battery Panic includes WidgetKit-ready SwiftUI widget views for macOS:

- Small: quick battery percentage and status.
- Medium: battery ring with threshold and power state.
- Large: full Battery Panic dashboard style.

The widget reads a local battery snapshot written by the app. No network calls, no accounts, no analytics.

> Note: Real macOS widgets require a WidgetKit Extension target in Xcode.
