Version 0.5.11

Charging reminders and stronger critical alerts.

This update adds a calm charging reminder, a more urgent 2% critical mode, stronger release checks, and final polish for the public 0.5.11 release.

Open GitHub Releases Join Discord View GitHub

Charging Reminder

  • New charging reminder setting.
  • Enabled by default at 80%.
  • Adjustable from 50% to 100%.
  • Shows a short green-blue overlay while plugged in.
  • Appears once per charging session.

Critical 2% Mode

  • At 2% or below, the overlay switches to CRITICAL BATTERY.
  • Stronger red pulse and glow.
  • Menu status can show the urgent critical state.

Sound Fixes

  • Apple system sounds such as Basso, Blow, Funk, and Ping repeat during active alarms.
  • Battery Panic Siren keeps its original one-shot sound.
  • Preview Red Screen stops overlay and sound after about four seconds.

Quality Checks

  • Expanded GitHub Actions coverage.
  • Swift and Xcode builds are checked.
  • ZIP, DMG, signing, appcast, release docs, and secrets are verified.
