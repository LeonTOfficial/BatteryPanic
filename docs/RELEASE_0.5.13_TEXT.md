# Battery Panic 0.5.13

Battery Panic 0.5.13 is a small visual hotfix for the red low-battery overlay.

## What's new

- Fixed the red warning card text alignment.
- Battery percentages such as `10%` and `20%` no longer overlap or crowd the battery icon.
- The fix applies to both Preview Alarm and real low-battery alerts.
- The headline spacing and title size were tuned while keeping the existing overlay design.

## Download

Attach these files to this GitHub release:

- `outputs/Battery.Panic.0.5.13.dmg`
- `outputs/Battery.Panic.0.5.13.zip`

Recommended for normal users:

1. Download `Battery.Panic.0.5.13.dmg`.
2. Drag Battery Panic into Applications.
3. If macOS blocks the first launch, open System Settings -> Privacy & Security and click Open Anyway.

## Notes

Battery Panic is open source and locally/ad-hoc signed. It is not Apple-notarized yet, so macOS may show the normal first-launch security warning for non-notarized apps.
