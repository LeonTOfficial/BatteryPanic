Battery Panic 0.6.0

Your battery, clearly explained.

A native dashboard now combines the Mac's real battery state with a local battery history, exact samples, and honest short-term trends.

Live native status

See the real percentage, power state, remaining time when available, and battery health.

Seven days, local only

Explore 30 minutes, one hour, one day, or one week without sending battery data off the Mac.

Release highlights

  • Hover for the exact recorded percentage and observation time.
  • Follow a smooth measured curve on a dynamically padded scale.
  • See green only across intervals actually reported as charging.
  • Use robust average-rate and short forecast guidance when enough data exists.
  • Recognize an active snooze from the red menu bar percentage.
  • Leave the unused widget, App Group remnants, and fake 68% fallback behind.
  • Benefit from hardened runtime state handling and Sparkle 2.9.5.

Exact history

The chart and hover use recorded observations. Adapter power without active charging stays distinct.

Honest guidance

Average rate and forecasts wait for enough uninterrupted data instead of guessing from a brief change.

Visible snooze

Only the percentage pulses during a low-battery pause; Reduce Motion shows the same state without animation.

Local and bounded

History stays in Application Support for no more than seven days and is not sent to an account or analytics service.

Apple silicon

The current release package is arm64 for Apple silicon Macs running macOS 13 or later.

Signing note

This build is ad-hoc signed and not Apple-notarized, so first launch may require approval in Privacy & Security.
