Battery Panic · 0.7.0

What’s new in this update

Updates are easier to notice, battery history is easier to explore, and every chart detail remains tied to real measurements from your Mac.

Updates appear when Battery Panic opens

A new version comes to the front immediately; no-update checks stay quiet.

New

  • Quiet update checks on launch, login start, and app reopen.
  • Calculated chart forecasts for 30 minutes, one hour, and one day.
  • One charging bolt centered on every visible charging section.

Improved

  • An underlined, inline history selector that keeps the menu open.
  • A clearer grid and a compact left-to-right chart reveal.
  • Neutral dashed gaps when day or week history was not recorded.
  • Consistently aligned symbols and labels in every menu action.

Fixed

  • The hover marker now sits exactly on the visible smoothed line.
  • Hover percentage and time always come from a recorded sample.
  • The menu always starts with the useful Last 30 min view.

Battery history remains local, bounded to seven days, and is never replaced with demo data in release builds.
