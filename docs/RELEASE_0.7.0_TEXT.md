# Battery Panic 0.7.0

Battery Panic 0.7.0 makes update notices more reliable and gives the native battery-history dashboard a clearer, more exact chart.

## Download

- Recommended: `Battery.Panic.0.7.0.dmg`
- Fallback: `Battery.Panic.0.7.0.zip`

## Install with DMG

1. Download `Battery.Panic.0.7.0.dmg`.
2. Open it.
3. Drag `Battery Panic.app` into Applications.
4. Open Battery Panic from Applications.

If macOS warns that the developer cannot be verified, open Privacy & Security settings, scroll to the bottom, and choose **Open Anyway** / **Dennoch öffnen**.

## What's new

- Quiet update checks on launch, login start, and reopen show Sparkle only when a newer release exists.
- Release notes now have a clearer summary and an accessible scroll cue.
- Last 30 min is restored whenever the menu opens, with an inline history-range selector that keeps the menu open.
- The chart reveals smoothly from left to right and shows polished grids, lines, areas, charging bolts, and supported forecasts.
- Hover stays on real curve points and continues to report exact recorded percentage and time values.
- Day and week labels appear only on hover and use real clock or weekday positions.
- Recording pauses in day and week views appear as neutral dashed gaps between real endpoints, without invented measurements.
- Menu action symbols and text are optically centered on one baseline.

## Privacy

- No analytics.
- No telemetry.
- No tracking.
- No account required.
- Battery history remains local and is retained for no more than seven days.

## Distribution

This release is an `arm64` build for macOS 13 or later with an ad-hoc signature. It is not Developer ID signed, not Apple-notarized, and has no GitHub artifact attestation. macOS may require **Open Anyway** on first launch.
