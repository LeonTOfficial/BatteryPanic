# Contributing

Thanks for checking out Battery Panic.

## Local Workflow

```bash
./scripts/run_tests.sh
./scripts/build_app.sh
```

Open the project in Xcode by opening `Package.swift`.

## Project Style

- Keep code modular.
- Keep UI native to macOS.
- Avoid one-file rewrites.
- Keep the app local-first and privacy-friendly.
- Add or update tests when changing alarm logic.

## Pull Requests

Please include:

- A short summary of the user-facing change.
- Test results.
- Screenshots or screen recordings for UI changes when possible.
- Any privacy or permission impact.
